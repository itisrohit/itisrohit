## About This Portfolio Website

This is a custom-built, interactive portfolio site designed to showcase not just my work, but also my engineering style and playful approach to web development. The site is crafted with modern React (Next.js), Framer Motion for smooth animations, and a focus on both performance and delightful user experience.

### ✨ Interactive & Visual Features
- **Dynamic System Dashboard:** Live-simulated system metrics, deployment logs, and animated UI elements for a "developer dashboard" feel.
- **Terminal Experiences:** Includes both a demo terminal (with animated output) and a fully interactive terminal where visitors can type commands like `help`, `about`, `skills`, and more.
- **Animated Backgrounds:** Subtle gradients, floating code symbols, and particle effects create a premium, tech-inspired atmosphere.
- **Spotify Widget:** Shows what I'm currently listening to, in real time.

### 🥚 Easter Eggs & Fun Details
- **Konami Code:** Enter the classic Konami code (↑ ↑ ↓ ↓ ← → ← → B A) anywhere on the site to unlock a special message.
- **Hacker Mode:** Press the `*` key to toggle a "hacker mode" with Matrix-style rain, green-glitch effects, and a custom cursor.
- **404 Corner Trap:** Move your mouse into any corner of the screen for a chance to trigger a playful 404 warning.
- **Click Sounds:** Every mouse click plays a subtle, custom-generated sound for tactile feedback.

All these details are designed to make the site not just a portfolio, but a fun, interactive playground for visitors and potential collaborators.
