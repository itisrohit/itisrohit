# /portfolio

Next.js portfolio for showcasing distributed systems research and software development. 

## Stack
- Next.js 16 (React 19)
- Tailwind CSS
- GSAP / Lenis (Motion)
- Bun (Runtime)

## Development
```bash
bun dev
```

## Internal Structure
- `src/app/data.ts`: Technical metadata and capability clusters.
- `src/app/components/`: Reusable animated SVG components and layout tiers.
- `src/styles/`: Global CSS tokens and high-performance layout resets.
